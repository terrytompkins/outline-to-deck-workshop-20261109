2Outline first: the method in one picture

  • Phase 1: build a numbered Markdown outline with Claude, and revise it as text until it's right.
  • The gate: the presenter approves the outline, and the approval is written down.
  • Phase 2: Claude builds the deck from the approved outline.
  • Anthropic gives the same advice for Claude Code: have Claude interview you, write the spec to a file, then build from it in a fresh session.

2.1Phase 1: the outline

  • Claude researches the topic. Your notes are leads, not the limit.
  • Each section becomes a slide: top-level sections run across, subsections go below.
  • Revise by section number ("revise 4.2"). From v0.2 on, numbers don't change.
Tip

Ask Claude to interview you before it drafts anything, a few questions at a time.

Source: Best practices for Claude Code

2.2The approval gate

  • DECISIONS.md is a dated log. Claude's suggestions are Proposed; only the approver makes them Decided.
  • Phase 2 starts only when the log has the approval line.
Watch out

Without a recorded approval, a casual "can I see one slide?" starts the deck early, and the deck drifts from the outline.

2.3Phase 2: the deck

  • Start a fresh chat. Claude builds from the approved outline as written, without new research.
  • First pass: title, agenda, and every top-level slide. Second pass: the detail slides.
  • Later content changes go to the outline first; then only those slides are rebuilt.
