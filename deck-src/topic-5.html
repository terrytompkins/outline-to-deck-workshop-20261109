5Building and checking the deck

  • Claude builds one self-contained web page you can host: topics run left to right, details go down.
  • Every slide is checked before the deck is called done.
  • Review it in a real browser.
Source: Reveal.js: vertical slides

5.1Two-dimensional decks

  • Reveal.js: horizontal slides for the walk-through, vertical slides for depth.
  • The library loads from a pinned version on cdnjs. The latest listed is 6.0.2.
  • Press S for the speaker view with the notes.
As of November 5, 2026Sources: Reveal.js: vertical slides · cdnjs: reveal.js

5.2The check script

  • tools/check-deck.py checks every slide: visible, no overflow, no footer collision, diagrams drawn, no console errors, no leaked tags.
Watch out

Claude's in-chat file preview can't load the deck's libraries, so a correct deck can look broken there. Test in a real browser.

5.3Other ways to finish

  • Claude Slides now works in any conversation (beta on Enterprise plans). The outline-first part works the same whatever builds the deck.
  • This template builds Reveal.js because it gives a two-dimensional deck that can be hosted as one file.
