# Outline First, Toons style

A 35-slide deck for the talk "Outline First". It uses [`STYLE-TOONS.md`](STYLE-TOONS.md). The outline is the same one that makes the Field Guide version, so you can compare two styles of one outline.

Open [`deck.html`](deck.html) in a browser. It loads Reveal.js and Mermaid from cdnjs, so it needs internet. Use the arrow keys: left and right move between topics, down opens a topic's detail slides. Press **S** for the speaker view.

## What to know

- This is a test deck. The outline has a test approval only. Six `TBD` chips remain on the slides.
- `deck.html` is a copy of `outline-first-toons.html` on branch `test/style-toons`. `deck-src/build.py` writes that file. One change: slide 4.3 shows the Field Guide demo deck in a frame, and this copy points to `../field-guide-demo/deck.html`. The original points to `examples/field-guide-demo/deck.html`.
- If you move this folder, the frame on slide 4.3 stays blank unless the Field Guide demo moves with it.
- `STYLE-TOONS.md` here is a copy of `knowledge/styles/STYLE-TOONS.md`. Change the original, then copy it again.
- The style uses no studio characters, logos, or catchphrases.
